# FishMap Architecture & Design Diagrams

This directory stores visual models, architectural diagrams, entity-relationship (ER) diagrams, and sequence charts for the FishMap platform.

## Contents & Structure

- System architecture diagrams illustrating API Gateway routing, microservice domain boundaries, and client connectivity.
- Database schema and entity-relationship models for per-service PostGIS and relational databases.
- Core workflow sequence diagrams (authentication lifecycle, catch recording, geospatial spot queries, and lure advisory).
